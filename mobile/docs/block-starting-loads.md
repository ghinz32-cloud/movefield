# Reuse a block with reviewed starting weights

In Plans, open Saved and previous blocks. Choose a saved block and preview its
starting date. Starting weights are optional and remain blank until chosen.
Expand the controls to enter weights or select a recorded reference. Check the
load convention, including per-hand dumbbell weights. Label machines by their
exact setup. Changing a machine label clears weights selected for that exercise.

Review your edits, then start the reviewed block. Each weight applies only to
that exercise's first exposure; later weights use the plan's existing rules.
The old workouts stay in history. A failed save keeps the draft for retry.
