# Grizzly Fitness Wautoma

User request, 12 October 2026: a separate Grizzly Fitness app with the same training features and a different UI. The official website supplied by the user is https://www.fitnessgrizzly.com/. Its homepage returned an explicit proxy destination denial in this environment. Domain additions were saved using the supported environment configuration workflow; that save does not activate access. The user subsequently uploaded the gym logo, so site access is no longer a prerequisite for branding. No membership details, gym services or official color palette have been inferred.

## Implementation

- A separate web entry at `/movefield/grizzly/`, built with `pnpm build:grizzly` into `.sites-runtime/github-pages-grizzly`.
- Shared `app/page.tsx`, components and canonical training modules. No copied workout engine, invented progress scores, altered training targets or automatic data migration.
- User-supplied grizzly/barbell/GF/location-arch logo, preserved byte-for-byte in `public/brand/grizzly-fitness-logo.jpg` and `mobile/assets/grizzly-fitness-logo.jpg` (54,782 bytes; 1280×593; SHA256 `8b97ad7dd972812b066cd5b919ff96d90d961ad00230230eb1faebd6e222b0f5`). The original appears on welcome, header, navigation, setup and appearance. Compact viewports trim empty black margins; the full welcome/disclosure view retains the whole photograph. Wild frost/charcoal defaults, optional amber/cream/woodland colors, claw scars and torn edges are custom app styling.
- Beast headings by default, with Metal, Bungee, Barlow and Inter choices; Inter controls/data. All fonts are self-hosted. Bungee came from the Google Fonts repository's `ofl/bungee/Bungee-Regular.ttf`; SHA256 `c4f5361ce120af3e6b9156d0bf379fa19cda2ea0cd18ac01fd99596c6bf66e3f`. The bundled SIL OFL notice includes attribution to the Bungee Project Authors. The web favicon is an SVG layout embedding the unchanged original JPEG. Native PNG icons are produced by the existing Expo asset compiler with `contain` on black square canvases, retaining the full supplied graphic. A generated reinterpretation was inspected and excluded from the app because it changed line details.
- Existing buttons, drop-downs, plan previews and disclosures stay in place. The prototype information sits behind Customize → About this version. No continuous bear animation, audio or animation around the rest timer.
- System/Light/Dark, seven Grizzly palettes, larger text, higher contrast, visible keyboard focus and both system/in-app reduced motion remain available. Arctic frost is the fresh Grizzly default; amber remains selectable. Movefield keeps six palettes with Volt green as its default.

## Separation

The web build namespaces the existing `training-studio` keys and locks as `grizzly-training-studio`, uses `grizzly-private-records-v1` for IndexedDB, `grizzly-cloud-outbox-v1` for the queue, and `grizzly-fitness:preferences:v1` for appearance. Its worker scope is `/movefield/grizzly/` and cache prefix is `grizzly-fitness-shell-`. Static Pages cannot call the optional Cloudflare account service; all training data stays local.

Native `EXPO_PUBLIC_APP_VARIANT=grizzly` selects a separate Expo name/slug, `com.ghinz32.grizzlyfitness.prototype` install ID, `grizzlyfitness` callback scheme and `grizzly-fitness.` storage/key namespace. SQLite uses `grizzly-fitness.movefield-private-records-v1.db`. Reminder kinds/IDs and temporary export files also have separate prefixes, including in Expo Go. The normal Movefield config and stored identifiers remain unchanged. The portable vault format remains `movefield-vault`; branding must never rename a cryptographic format. Deliberately imported backups remain interoperable.

From `mobile`, use `npm run start:grizzly` or `npm run export:grizzly`. In this managed environment, the tested export is `EXPO_OFFLINE=1 EXPO_NO_TELEMETRY=1 CI=1 XDG_CACHE_HOME=/workspace/movefield/.sites-runtime/cache npm run export:grizzly -- --max-workers 4`. Default native commands select Movefield. See `mobile/GRIZZLY.md`; clear Metro when switching flavors. Both export commands now include `--clear`: a reused Metro transform cache produced identical Grizzly/default bundles during qualification and was rejected. Distinct final bundle hashes are required. Grizzly has separate API URL/qualification flags and cannot accidentally use the Movefield cloud origin.
