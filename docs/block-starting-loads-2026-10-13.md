# Reviewed starting weights for reused blocks

Saved and previous blocks now offer an optional starting-weight editor on both
web brands and native brands. Open the saved block, preview its dates, expand
Starting weights, and enter a weight or select a recorded reference. Review
edited weights before starting. Blank remains unknown; an explicit zero is
separate. A failed save keeps the draft for retry.

Each choice applies to the first exposure to an exercise and its training role.
It does not freeze weights across the block. Later workouts retain their existing
progression rules. Sets, rep ranges, rest, creator stages and source editions,
supersets, completed history and the original saved block are preserved.

References contain the actual load of the latest complete comparable workout,
with the same exercise, work sets, target range, source role/stage and machine
setup. Partial, assisted, unequal-load, future, sample and concern-flagged work
cannot supply a reference. The existing five-week window is a conservative
product review policy, not a physiological boundary or an individual readiness
assessment. No maximum, reset percentage or increase is inferred. Coach/manual
plans retain owner-directed targets. Youth weights need a qualified supervisor.

Equipment maxima apply in canonical kilograms. Machine changes clear drafted
weights for every role of that exercise, and only explicitly accepted setup
labels are saved. History, custom exercise definitions, equipment, setup,
calendar and profile changes invalidate an earlier block review. Directly
modified target previews are rejected. The shared implementation is retained
in the native snapshot and verified in both entrypoints.

Android preview versions advance to Movefield 0.1.3/versionCode 4 and Grizzly
0.1.2/versionCode 3. Movefield keeps the historical package and test certificate;
Grizzly keeps its separate identity. Physical old/new installation and platform
storage/restart/notifications remain unperformed. The existing upstream native
advisories, signing/store and connected-provider gates stay open.

This is a bounded next-block load review. It does not implement individualized
next-block volume or a creator-specific terminal-stage reset, and does not
complete the six-prompt task register. Exact checks and publication/build
receipts are recorded beside this document.

A final regression reproduced a hidden chosen weight on an exercise with
automatic progression disabled. The logger now displays that explicitly
reviewed weight while leaving automatic increases unavailable. The case is
retained in the shared gate. The prior 0.1.2/0.1.1 APKs are superseded.
